# Sales & Revenue Performance Dashboard

## 📊 Project Overview

This project is an interactive **Sales & Revenue Performance Dashboard** built using **Microsoft Excel**.

The project focuses on cleaning and analyzing sales transaction data and presenting key business insights through an interactive dashboard.

## 🛠️ Tools & Skills

- Microsoft Excel
- Data Cleaning
- Data Formatting
- PivotTables
- PivotCharts
- Slicers
- KPI Development
- Data Visualization
- Exploratory Data Analysis

## 🧹 Data Cleaning

The dataset was cleaned and prepared before analysis by:

- Handling duplicate records
- Handling null/missing values
- Identifying and handling negative or invalid values
- Formatting dates and numerical fields
- Checking data consistency

## 📈 Dashboard Features

### KPIs

- Total Sales
- Total Orders
- Average Order Value

### Visualizations

- Existing vs New Customers
- Total Sales by Month
- Order Status
- Product Sales by Region
- Payment Method Distribution

### Interactive Slicers

- Region
- Month
- Product
- Customer Type
- Other relevant filters

## 🔍 Analysis Performed

The dashboard helps analyze:

- Overall sales performance
- Monthly sales trends
- Existing vs New Customers
- Product performance across regions
- Payment method distribution
- Order status distribution

## 🔄 Project Workflow

**Data → Data Cleaning → PivotTables → KPIs → PivotCharts → Slicers → Interactive Dashboard**
